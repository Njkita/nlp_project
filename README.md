# RuOpinionNE-2024: извлечение кортежей мнений

Дообучение T-pro-it-2.0 (Qwen3-32B) под извлечение кортежей мнений
(источник, объект, выражение, тональность) из русских новостей.
Итог: F1 = 0.460 на валидации против 0.34 у лучшей системы фазы валидации
и 0.41 у победителя фазы теста (см. [RESULTS.md](RESULTS.md)).

## Данные
Данные соревнования не входят в репозиторий, клонируются отдельно:

    git clone https://github.com/dialogue-evaluation/RuOpinionNE-2024

Публично размечена только валидация (`validation_labeled.jsonl`).
Официальный скрипт оценки продублирован в `src/ruopin/official_eval.py`.

## Код
- `src/ruopin/serialize.py`: сериализация кортежей в JSON, парсинг выхода модели,
  восстановление символьных смещений, санитизация под официальный скрипт.
- `src/ruopin/score.py`: обёртка официальной метрики (взвешенный tuple-F1).
- `src/ruopin/prompts.py`: промпты и формат обучающих примеров.
- `src/ruopin/build_sft.py`: сборка SFT-датасета.
- `src/ruopin/train_qlora.py`: QLoRA-дообучение (4-bit nf4, LoRA на всех линейных слоях).
- `src/ruopin/infer_vllm.py`: инференс через vLLM (zero/few-shot, self-consistency).
- `src/ruopin/aggregate.py`: голосование по сэмплам, подбор порога, скоринг.
- `src/ruopin/merge_lora.py`: мёрж адаптера в bf16.
- `src/ruopin/stats.py`: статистика по наборам.
- `src/ruopin/error_analysis.py`: разбор ошибок по типам источника и полярности.
- `tests/roundtrip.py`: проверка, что формат и парсер не теряют информацию
  (эталон, сериализация, парсинг, метрика дают около 1.0).

## Запуск
Нужна одна GPU от 40 ГБ. Установка зависимостей: `pip install -r requirements.txt`.
Полный пайплайн собран в `scripts/run.sh` (запускать из корня репозитория с активным venv).

## Метрика
Официальный скрипт `RuOpinionNE-2024/codalab/evaluation.py`. Кортеж засчитывается
при пересечении источника, объекта и выражения хотя бы на один токен и точном
совпадении тональности, а вклад взвешивается долей пересечения.
