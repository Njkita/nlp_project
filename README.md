# RuOpinionNE-2024: извлечение кортежей мнений

Дообучение T-pro-it-2.0 (Qwen3-32B) под извлечение кортежей мнений
(источник, объект, выражение, тональность) из русских новостей.
Итог: F1 = 0.460 на валидации против 0.34 у лучшей системы фазы валидации
(см. [RESULTS.md](RESULTS.md), отчёт в [report/main.pdf](report/main.pdf)).

## Данные
В репозиторий не входят, клонируются рядом:

    git clone https://github.com/dialogue-evaluation/RuOpinionNE-2024

Публично размечена только валидация (`validation_labeled.jsonl`); разметка теста
скрыта, Codalab закрыт. Официальный скрипт оценки продублирован в
`src/ruopin/official_eval.py`.

## Требования
- GPU от 40 ГБ (обучение и инференс идут в 4-бит). Всё считалось на одной A100 80GB.
- Локальная копия модели `t-tech/T-pro-it-2.0`; путь задаётся переменной `MODEL`.
- Версии стека привязаны к драйверу. На драйвере CUDA 12.8 рабочая связка:
  `torch 2.7 (cu12x)`, `vllm==0.9.2`, `transformers==4.52.4`, `peft`, `bitsandbytes`,
  `accelerate`. Свежие `torch`/`vllm` тянут CUDA 13 и на этом драйвере не стартуют;
  `transformers>=4.53` конфликтует с `vllm 0.9.2` (`aimv2 already used`).
- vLLM грузит базовую модель в 4-бит (`--quant bitsandbytes`) и обслуживает её
  с LoRA-адаптером, поэтому отдельный мёрж для оценки не нужен.

## Код
- `src/ruopin/serialize.py`: сериализация кортежей в JSON, парсинг выхода модели,
  восстановление символьных смещений, санитизация под официальный скрипт.
- `src/ruopin/score.py`: обёртка официальной метрики (взвешенный tuple-F1).
- `src/ruopin/prompts.py`: промпты и формат обучающих примеров.
- `src/ruopin/build_sft.py`: сборка SFT-датасета.
- `src/ruopin/train_qlora.py`: QLoRA-дообучение, адаптер сохраняется после каждой эпохи.
- `src/ruopin/infer_vllm.py`: инференс через vLLM (zero/few-shot, self-consistency).
- `src/ruopin/aggregate.py`: голосование по сэмплам, подбор порога, скоринг.
- `src/ruopin/merge_lora.py`: мёрж адаптера в bf16 (опционально).
- `src/ruopin/stats.py`, `src/ruopin/error_analysis.py`: статистика и разбор ошибок.
- `tests/roundtrip.py`: проверка, что формат и парсер не теряют информацию.

## Запуск

    pip install -r requirements.txt
    export MODEL=/path/to/T-pro-it-2.0
    bash scripts/run.sh

`scripts/run.sh` создаёт `data/`, `outputs/`, `out/` и воспроизводит все таблицы
отчёта: статистику, бейзлайны, дообучение, оценку по эпохам, self-consistency и
разбор ошибок. На A100 один прогон greedy по валидации занимает порядка пяти минут,
self-consistency на пять сэмплов примерно впятеро дольше.

## Метрика
Кортеж засчитывается при пересечении источника, объекта и выражения хотя бы на
один токен и точном совпадении тональности; вклад взвешивается долей пересечения.
Порог голосования self-consistency подбирается на валидации (`--sweep`).
